Filosofi Arsitektur

Saya Tidak Membangun Fitur. Saya Merancang Sistem yang Bertahan.

Sebagai Tech Architect & pemilik bisnis F&B, saya memiliki perspektif operasional ganda. Saya menganalisis masalah langsung dari lapangan, lalu membangun sistem untuk menyelesaikannya.

Perangkat lunak bernilai bukan sekadar terbebas dari bug — melainkan arsitektur yang terbukti mempercepat alur kerja di lingkungan bisnis nyata, seperti manajemen ritel dan dapur katering.

Spesialisasi saya adalah ekosistem end-to-end: memadukan keandalan Laravel REST API di sisi server dengan ketangguhan Kotlin & Jetpack Compose di sisi mobile.
