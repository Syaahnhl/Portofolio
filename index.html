System Architecture

Kaching POS Offline-First Implementation

Tech Stack Pipeline

Layer 1: Mobile Edge

Kasir operasional dengan kapabilitas offline penuh.

  • > Kotlin + Jetpack Compose
  • > Room Database (Local)
  • > StateFlow & MVVM
Layer 2: Real-Time Sync

Penengah antrean data dan trigger live update ke Dapur.

  • > Laravel WebSockets
  • > WorkManager Background Sync
  • > Event Broadcasting
Layer 3: Core Engine

Manajemen Multi-Tenant, analitik, dan source of truth.

  • > Laravel 11 REST API
  • > MySQL Database
  • > DigitalOcean VPS (Ubuntu)

Kenapa Offline-First?

Dalam lingkungan retail F&B yang padat, downtime internet tidak boleh menghentikan transaksi kasir. Dengan menggunakan Room Database di Android, aplikasi menyimpan seluruh State menu dan transaksi secara lokal.

Ketika koneksi internet pulih, WorkManager secara otomatis menjalankan sinkronisasi latar belakang, melempar data transaksi ke server Laravel, dan menggunakan WebSockets untuk me-render pesanan baru secara real-time di layar Dapur (Kitchen Display System) tanpa perlu di-refresh.
